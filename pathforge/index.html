Workflow

From STL to the machine in four steps

Everything runs on your own computer. Nothing is uploaded.

  1. Import

    Open an STL from any CAD program. Assemblies split into parts you can click and rotate.

  2. Set up

    Tool size, feeds, stepdown, stock, and where zero is: top or bottom, corner or centre.

  3. Generate

    Roughing, exact waterline finishing of the walls, then a finishing pass over tops and floors.

  4. Check and save

    The program is cut on a virtual block. You save it once the check passes.

Safety check

The check reads the finished G-code

It replays the exact file your controller will run, on a block cut into 0.1 mm squares, and stops four kinds of mistake.

  • Gouges

    Any move that cuts into the part, measured to the thousandth of a millimetre.

  • Rapid crashes

    A G0 move that would travel through stock that hasn't been cut yet.

  • Cutting too deep

    Moves below the bottom of the part, into your vise, fixture or table.

  • Overloads

    The tool buried deeper than one layer across a wide area. These are the cuts that snap end mills.

Limits

What it doesn't do yet

So you know before you cut.

  • 3-axis only

    No 4th or 5th axis machining. You can tilt the part before cutting.

  • Flat end mills only

    Ball-nose tools are planned. A finer finish stepover gives smoother curves.

  • Windows only

    Windows 10 or 11, 64-bit.

  • Dry run every new job

    The check is a simulation. Run each new program in the air first with the feed turned down.

Before your first cut on a real machine

  1. Only run programs whose preview says PASSED.
  2. Check units, tool number and tool length offset match the file header.
  3. Touch off X0 Y0 and Z0 exactly where the header says.
  4. Clamp the stock and keep clamps out of the cutting area.
  5. Dry run first: Z raised or cutting air.
  6. First real cut with the feed override low and a hand on the stop button.

FAQ

Questions

Will it work with my machine?

PathForge CAM writes G-code for Tormach PathPilot, Haas, GRBL and Mach3/Mach4 controls. Most 3-axis mills and routers use one of these. If yours isn't listed, tell us when you sign up for update emails.

Do I need the internet to use it?

No. It runs on your computer. Your files are never uploaded.

Which files can I import?

STL files, both binary and text, from any CAD program.

Is it really free?

Yes, during the beta. The beta version is free for everyone until 31 January 2027, for learning and for paid jobs. The G-code you make is yours.

What happens after the beta?

The beta version stops working after 31 January 2027 and paid licences start. Planned prices: Academic free for students and teachers, Personal $299 one-time, Business $800 one-time. Sign up for update emails and we will tell you before the beta ends. The G-code you made stays yours.

Is it safe to download?

Download it only from this website. It is a plain folder: nothing is installed, it needs no admin rights, and it never sends data over the internet. You can check the file with the SHA-256 code shown in the download section.

Is it safe for my machine?

Every program is cut on a virtual block before you can save it normally, and the file header says exactly where to touch off. But no software knows your real machine, tool and clamps. Always dry run a new program first, with the feed turned down.

Something went wrong. What do I do?

PathForge saves error details to %APPDATA%\PathForge\error_log.txt on your computer. Send that file to us on WhatsApp with a short description.
