Docs and guides

Getting started

  1. Download PathForge CAM from the download section and unzip the folder anywhere, for example in Documents.
  2. Open PathForgeCAM.exe. No installer and no admin rights are needed. Read the safety notice, tick the box and start.
  3. Import STL (left panel). If the part arrives upside down or lying on its side, use Flip upside down or Y-up STL → Z-up.
  4. Pick your machine (right panel): Tormach, Haas, GRBL or Mach3/Mach4.
  5. Set up the job: tool, feeds, stock size and where zero is. The easiest way is Tool library / feeds.
  6. Choose a strategy (Full Job is the best start) and press Generate G-Code.
  7. Read the check. Save only when it says PASSED. Press Play G-code to watch it first.

Every number on screen is the same number that goes into the G-code. The white dot is X0 Y0 Z0.

Check your download is genuine

Every release has a SHA-256 code, a fingerprint of the file. If even one byte were changed, the code would be completely different.

  1. Open the folder where the zip was saved, click the address bar, type powershell and press Enter.
  2. Run this command:
Get-FileHash .\PathForgeCAM_Windows.zip

It must print exactly:

Older versions have their own codes on the changelog. See the VirusTotal scan report.

On VirusTotal, version 4.6 is clean on 65 of 66 virus scanners, including Microsoft Defender. One small scanner (Bkav) gives a generic warning that it often shows for any program built with Python and PyInstaller. If your own antivirus warns you, check the SHA-256 code above first.

"Windows protected your PC"

Windows shows this for new programs that are not code-signed yet. Click More info, check the name is PathForgeCAM.exe, then click Run anyway. Only do this for a copy downloaded from this website whose SHA-256 code matches.

Setting zero on your machine

The top of every G-code file says exactly where to touch off, for example:

(X0 Y0 = FRONT-LEFT CORNER OF STOCK)
(Z0 = TOP OF STOCK)
(CUT DEPTHS ARE NEGATIVE Z)
  • Z0 = top of stock (the usual choice): every cut goes to a negative Z. That is correct, not a mistake.
  • Z0 = bottom of stock: Z is the height above the bottom of the block (or above the base you left under the part).
  • X0 Y0 can be the front-left corner, the centre of the stock, or the same zero as the STL file.
  • Stand in front of the machine: X goes right, Y goes away from you, Z goes up. The app's 3D view starts from this operator's view.

Feeds and speeds with the tool library

  1. Click Tool library / feeds. Add your tools once: number, shape, diameter, corner radius, flutes and flute length.
  2. Pick your material. The window shows starting values for the selected tool.
  3. Click Use as TOOL 1. The job settings are filled in for you.

How the numbers are worked out: spindle speed from the cutting speed for the material, feed = RPM x flutes x chip load, stepdown as a share of the tool diameter. Everything is capped to your machine's top speed and feed, with a note when it is lowered.

These are safe starting values for carbide tools. Machines, holders and setups differ: start with the feed override low and adjust by sound and chips.

Choosing a strategy

Full JobMost parts. Roughing, exact waterline walls, then a parallel finish of tops and floors.
2.5D PocketPlates, pockets and steps with flat floors. Faster than Full Job on these.
Rough ClearRoughing only, leaving the skin for a later program.
Waterline ZSteep walls.
Parallel X / YCurved tops, best with a ball-nose tool.

Adaptive roughing (More options) uses a light stepover with a deep stepdown, so the tool load stays even.

Ball-nose, bull-nose and a second tool

  • Tool shape: More options → Tool & stock. Ball-nose for curved surfaces (use a small finish stepover), bull-nose for strong cutting with a smooth finish on slopes.
  • Second tool: in the tool library click Use as 2nd tool, or tick it in More options → 2nd tool. Tool 1 roughs, tool 2 cuts only where material was left and does all the finishing.
  • Each tool needs its own number, and its tool length offset set on the machine.

Drilling holes

  1. Add your drills to the tool library (shape: Drill).
  2. More options → Drilling: tick Drill small round holes and pick the material.
  • Holes smaller than your end mill are drilled with a drill of the same size (within 0.1 mm). Bigger holes are milled.
  • Shallow holes use G81. Holes deeper than 3 x the diameter use G83 peck drilling. GRBL has no drilling cycles, so every move is written out.
  • Through holes need stock below the part, so the drill can go all the way through into the base and not into your table.

Clamp and vise zones

More options → Clamps / keep-out. Add a box for each clamp, measured in G-code numbers: X and Y from X0 Y0, and the height of the top of the clamp above Z0. With Z0 on top of the stock, a clamp 5 mm higher than the stock is +5, and one 3 mm lower is -3.

Toolpaths keep a 0.5 mm air gap, the safe height is raised over the clamps, the preview draws them in red, and the checker reports any move that enters one.

The G-code player

  • After generating, press Play G-code in the preview, or open any file with G-code player (open file).
  • Play, pause, step one move at a time, or drag the slider. The current line is highlighted.
  • Check against the loaded part runs the full safety check on any file, using the stock and zero settings in the main window.
  • There is also a player in your browser on the home page.

First cut checklist

  1. Only run programs whose preview says PASSED.
  2. Check units, tool numbers and tool length offsets match the file header.
  3. Touch off X0 Y0 and Z0 exactly where the header says.
  4. Clamp the stock and keep clamps out of the cutting area, or mark them as clamp zones.
  5. Dry run first: Z raised, or cutting air.
  6. First real cut with the feed override low and a hand on the stop button.

Troubleshooting

The check says FAILEDRead the first error: it names the line. Common fixes: a smaller stepdown, a smaller tool, more stock margin, or moving a clamp zone.
The part is upside downUse Flip upside down, or Y-up STL → Z-up.
