Machining safety

CNC machines can cause serious injury and damage. PathForge CAM checks its G-code with a simulation, but no simulation can know your exact machine, fixture, tool or material.

  • You are responsible for checking every program before you run it.
  • Run every new program as a dry run first, with the feed turned down.
  • Check that the tool, zero point and machine settings in the file header match your machine.
