Changelog

What changed in every version, with the SHA-256 code of each download so you can check your copy.

  1. 4.7November 2026LATEST

    3D viewer and holder check

    • New 3D G-code viewer: the block is cut in 3D with the real tool (flutes, shank and holder), view buttons, operations list and live readout. Works offline, nothing is uploaded
    • Viewer safety check: rapids through material, shank and holder hits, clamp zones, cutting below the stock, spindle off, missing feed, very heavy cuts
    • Setup sheet: where zero is, work offset, travel used, first move, tool reach and a checklist
    • Tool load on every move, and load colours on the path
    • Realistic cutting time: speeding up and slowing down at every corner, per machine
    • Reads more G-code from other CAM programs: G91, G18/G19 arcs, G73/G82/G84/G85/G89, G54-G59 with G10
    • Holder and shank collision check in the app (set flute length, stickout and holder size)
    • Fix: arc radius at start and end now matches within 0.001 mm (GRBL could alarm)
    • Fix: rapids no longer clip the strip of stock beside a clamp with centre zero; clamp zones correct in inch jobs
    • 145 automatic checks and a 56-job machine safety audit before every release

    SHA-256

  2. 4.6November 2026

    Nine upgrades

    • Tool library with feeds and speeds by material
    • Ball-nose and bull-nose end mills, with exact maths
    • Two tools: rest machining with a smaller second tool
    • Drilling with G81 / G83 and the new 2.5D Pocket strategy
    • Clamp and vise keep-out zones
    • G-code player that can check any G-code file
    • Arcs (G2/G3) for smaller files and smoother motion
    • Adaptive roughing
    • Stock below the part
    • Fix: roughing could return across a corner when ramping into an open path; the checker always caught it, now fixed at the source
    • Fix: roughing no longer leaves a thin skin of stock against clamp zones (a later pass had to cut it in one go); clamps now get a clean 0.5 mm air gap
    • 61 automatic checks before every release

    SHA-256 E181DF0D109388662EEF1E578A9B72613C875B37E4B29806EE3D5E0BFC79788C

  3. 4.51 November 2026

    From a real Tormach test

    • The app and preview now show the same coordinates as the G-code, with the stock box, an X0 Y0 Z0 marker and X+/Y+/Z+ arrows
    • Operator's camera view: X right, Y away from you, Z up
    • Header notes: cut depths are negative Z, cuts top down layer by layer
    • One-click Flip upside down, Y-up STL to Z-up and Reset orientation
    • New automatic tests: no flipped or mirrored axes, every cut at Z0 or below, top-down layers
